КАК ПОЛУЧИТЬ .APK

Способ 1 (с телефона или ПК, без Android Studio):
1. Создай бесплатный аккаунт на github.com и новый репозиторий.
2. Загрузи в него ВСЁ содержимое этого архива (вместе с папкой .github).
3. Открой вкладку Actions -> Build APK -> Run workflow.
4. Через 3-5 минут внутри запуска появится файл Ozonozon-apk. Скачай, внутри app-debug.apk. Установи его на телефон.

Способ 2 (Android Studio):
Открой папку как проект и выбери Build -> Build APK(s).

Игра лежит в app/src/main/assets/index.html (работает офлайн, сохранения хранятся в телефоне).
